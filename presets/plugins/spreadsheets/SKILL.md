# spreadsheets:Excel/CSV 账表勾稽审计清单

审计对象是**数字之间的勾稽关系**,不是格式美观。凡数字必须能互证:
横能加总、纵能平衡、跨期能勾稽。配套脚本:`scripts/xlsx_audit.py`(见下)。

## 一、勾稽检查清单

| # | 检查项 | 判定标准 | 严重级 |
|---|--------|----------|--------|
| 1 | 合计校验 | "合计/总计/小计"行的每个数值列 = 其上方数据行同列之和(容差内);合计行缺失视为信息级,不得静默跳过 | 不等:error;缺失:info |
| 2 | 借贷平衡 | 有"借方/贷方"(或"借/贷")列时,∑借方 = ∑贷方(数据行,剔除合计行);差额超容差即记 error | 差≠0:error |
| 3 | 同比勾稽 | 有"本期/上期/同比"列时:同比 ≈ (本期-上期)/\|上期\|×100;分母为 0 而同比列有值视为 error | 超容差:error |
| 4 | 环比勾稽 | 有"上月/环比"列时:环比 ≈ (本期-上月)/\|上月\|×100;与同比共用容差 | 超容差:error |
| 5 | 单位与口径 | 同列混用万元/元、含千分位逗号或"——"占位符 → 转数失败率超 5% 记 warn,提示人工确认口径 | warn |

## 二、判定纪律

- 容差缺省 0.01(绝对值);金额表建议按量级放行到 0.01×行数。
- 勾稽失败必须定位到行(报"第 N 行,列 X:应为 a,实为 b"),禁止只报总数不符。
- 规则不适用(无对应列)输出 info 级"跳过",便于复核者区分"查过没问题"与"没查"。

## 三、脚本用法(xlsx_audit.py)

```bash
# Excel(需 openpyxl;缺库时脚本会提示 pip install openpyxl 并以退出码 2 退出)
python3 scripts/xlsx_audit.py 决算表.xlsx --sheet 收入明细

# CSV(纯标准库,无需安装任何包)
python3 scripts/xlsx_audit.py 台账.csv --json

# 放宽容差(金额大表)
python3 scripts/xlsx_audit.py 台账.csv --tolerance 0.5
```

退出码:0 = 无 error;1 = 存在 error(含勾稽不平);2 = 用法/环境问题(缺库、文件不存在)。
`--json` 输出结构化 findings(`{rule, severity, row, detail}`),供管线消费。
