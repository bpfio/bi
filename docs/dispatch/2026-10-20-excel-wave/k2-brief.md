## 设计要求（方法论文档须含以下六章，每章可执行、给出具体检查点/命令形态/判定标准）
1. **验证金字塔**：单测/集成/伪端点覆盖/真机效用/dogfood/评测六层的定位、成本、覆盖目标、何时可跳过
2. **变更分级门禁矩阵**：按变更类型（纯文档/config 键面/单工具/核心循环/TUI/发布）列出必跑门禁组合与最低通过标准
3. **升级工作流**：需求→派单→验收→合并→发布→归档的标准管线，含台账卡状态机（planned/running/review/closed）与悬空归零铁律
4. **回归与评测节奏**：每提交/每发版/每周/每季度的固定评测面（幻觉率探针、覆盖度抽检、性能基线、依赖漂移）
5. **质量风险登记册**：CLI agent 特有风险（模型漂移、端点限流 429、上下文膨胀、幻觉回归、子代理失控、崩溃类测试自杀）与对冲手段
6. **度量指标**：定义「优秀 CLI agent」的可度量指标集（幻觉率/任务完成率/回合效率/token 成本/崩溃率等），给出每指标测量方法与当前 bi 基线值
